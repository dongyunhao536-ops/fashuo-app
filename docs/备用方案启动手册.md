## 2. 方案分档（按故障场景选）

### 0 档：Codex Desktop 不可用，但 Codex CLI 仍可用
在 `D:\fashuo-app` 启动 Codex CLI；它会读取同一份 `AGENTS.md` 与 `.agents/skills/`，账本和脚本均不变。**优先试这档。**

### A 档：现役高质量路径——ChatGPT 订阅 + Codex Desktop/CLI
已投入使用。Desktop 不可用时运行 `cd D:\fashuo-app && codex`，按 §4 开场即可。
- 配置在 `C:\Users\Administrator\.codex\config.toml`：走 ChatGPT 订阅鉴权（**别配 OPENAI_API_KEY**，按 token 计费和 Claude API 一个价位）；workspace-write 沙箱 + 放开网络（脚本连 Supabase 要用）；fashuo-app / fashuo 两目录已设 trusted。
- Codex 原生读取仓库根的 `AGENTS.md`，并自动发现 `.agents/skills/`。
- 已知坑：① Plus 有周滚动用量上限，密集备考期可能撞顶，撞了当天降 B/C 档兜底；② 网络/国际支付门槛比 Anthropic 更高；③ 升级用 `codex update`（npm 装的主包只是壳，真身在 `@openai/codex-win32-x64` 别名包，镜像源漏装时用别名语法补：`npm i -g "@openai/codex-win32-x64@npm:@openai/codex@<版本>-win32-x64"`）。
- **切换前先平行验证**：同一批错题让它按 cuoti-fupan 的 SKILL.md 出一轮题，核对"不换壳"出题质量 + 判题是否贴《考试分析》原文、敢不敢说"查不到"。这两项过关整套就过关。

### B 档：低成本——开源 CLI + 国产模型
OpenCode / Crush 等开源 agent CLI（都读 AGENTS.md、能跑 shell 读写文件）+ GLM 编码包月（~¥20/月）或 DeepSeek API（~¥1-2/百万 token）。法硕是纯中文任务，国产模型在中文法律语料上最不吃亏。

### C 档：零成本 CLI
Qwen Code（免费额度 ~2000 次/天）或 iFlow 心流 CLI（免费接 Qwen/Kimi/DeepSeek，国内网络友好）。日常带背、复盘、周报够用；出题深度略降。

### D 档：最保底——网页版 + 手动跑脚本（不依赖任何工具）
人肉当 harness，闭环一步不缺：
1. 跑数据命令，如 `node --env-file=.env.local scripts/cuoti.mjs list`；
2. 把【SKILL.md 全文 + 命令输出 + `Claude记忆备份` 里相关画像文件】贴进网页版 DeepSeek/Kimi/GLM（免费）；现役规则也可从 `Codex规则备份` 取回；
3. 模型出题/判题/写周报；
4. 按 SKILL.md 里写的写命令（absorb / log / save…）手动落库。
