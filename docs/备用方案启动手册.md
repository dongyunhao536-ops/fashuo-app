## 0. 一句话结论

这套系统四层里只有一层依赖 Claude Code 客户端。灾备时：**APP、数据、脚本原样能用，只需给"智能层"换一个会读文件、跑命令的模型**，然后念开场词（见 §4）。

| 层 | 是什么 | 依赖 Claude 客户端？ | 灾备动作 |
|---|---|---|---|
| APP | ECS 47.103.148.124:8443 上的 Next.js，AI 走七牛云（`LLM_BASE_URL`，Anthropic 协议） | ❌ | 无。答疑/教练应急照常用手机 APP |
| 数据层 | Supabase 共享账本 + fashuo-archive git 仓（D:\fashuo）+ `.local/`（英语真题、评估报告） | ❌ | 无 |
| 脚本层 | `scripts/*.mjs`（coach/cuoti/weekly/dashboard…），纯 Node 直连 Supabase | ❌ | 无。`node --env-file=.env.local scripts/xxx.mjs` 照跑 |
| 智能层 | 7 个 PC skills（`.claude/skills/*/SKILL.md` = 操作手册）+ 记忆（云的画像/弱点/决策） | ✅ 唯一依赖 | 按 §2 选档接新模型，按 §4 开场 |

## 1. 灾备资产清单（东西都在哪）

- **7 个 skills**：`fashuo-app/.claude/skills/`（已进 git，GitHub 有）。本质是纯 markdown SOP，任何智能体可执行。
- **脚本**：`fashuo-app/scripts/`（已进 git）。
- **记忆备份**：`D:\fashuo\Claude记忆备份\`（→ GitHub fashuo-archive 仓）。由 `scripts/backup-memory.mjs` 自动镜像自 `C:\Users\Administrator\.claude\projects\D--fashuo-app\memory\`，Windows 计划任务 `ClaudeMemoryBackup` 每日 22:30 跑。**这是换 harness 时最金贵的东西**——云的能力画像、弱点模式、几个月的判题纪律沉淀全在里面。
- **PC 工作区备份**：`D:\fashuo\PC工作区备份\`（→ 同一 fashuo-archive 仓）。同一脚本/同一计划任务顺带镜像 `fashuo-app/.local/`（带背挂账台账、评估报告、周报草稿、英语真题库；排除 `英语真题/_raw` 的 29MB 原始 PDF）。2026-07-17 前 `.local` 不在任何备份链里（.gitignore 排除+备份不覆盖），带背挂账丢了就是复检历史清零——已补。
- **方法论/背诵论**：`fashuo-app/docs/方法论/`、`docs/背诵论/`（已进 git）。
- **`.env.local`（⚠️ 不在 git 里，丢了要重配）**：脚本层最少需三个——`NEXT_PUBLIC_SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`（值去 Supabase 控制台拿），以及 `NODE_OPTIONS=--import=file:///D:/fashuo-app/scripts/lib/trust-fashuo-ca.mjs`（ECS 8443 是自签证书，这行把 CA 挂进 Node 默认池；CA 副本在 `.local/fashuo-ca.crt`、源在 ECS `/opt/fashuo-ca.crt`；模板见 `.env.local.example`）。APP 侧另有 `LLM_BASE_URL`/`LLM_API_KEY`（七牛云）等，见 ECS 上的 `.env.production`。
- **英语真题库**：`fashuo-app/.local/英语真题/`（不在 fashuo-app git；已随 `.local` 每日自动备份进 `D:\fashuo\PC工作区备份\`，`_raw` 原始 PDF 除外——那份只在本机，丢了可从购买源重下）。

## 2. 方案分档（按故障场景选）

### 0 档：客户端还能用，只是 Claude 账号/额度出问题
给 Claude Code 配环境变量指向国产 Anthropic 兼容端点（GLM / Kimi / DeepSeek 都有）：
`ANTHROPIC_BASE_URL=<兼容端点>` + `ANTHROPIC_API_KEY=<该家 key>`。
skills、权限、白名单全部原样，迁移成本≈0。**优先试这档。**

### A 档：不降质量（云 7-10 意向）——ChatGPT 订阅 + Codex CLI
**✅ 已装好配好（2026-07-11，codex-cli 0.144.1，原生 Windows 版，`codex doctor` 全绿）**，启用只差两步：
1. 开代理（OpenAI 国内直连不通，doctor 已实测 WebSocket 被断、HTTPS 可降级）；
2. `codex login` → 浏览器 ChatGPT 账号 OAuth（需 Plus 订阅）。
然后 `cd D:\fashuo-app && codex`，念 §4 开场词即可。
- 配置在 `C:\Users\Administrator\.codex\config.toml`：走 ChatGPT 订阅鉴权（**别配 OPENAI_API_KEY**，按 token 计费和 Claude API 一个价位）；workspace-write 沙箱 + 放开网络（脚本连 Supabase 要用）；fashuo-app / fashuo 两目录已设 trusted。
- Codex 原生读仓库根的 `AGENTS.md`；skills 用 §4 开场词加载。
- 已知坑：① Plus 有周滚动用量上限，密集备考期可能撞顶，撞了当天降 B/C 档兜底；② 网络/国际支付门槛比 Anthropic 更高；③ 升级用 `codex update`（npm 装的主包只是壳，真身在 `@openai/codex-win32-x64` 别名包，镜像源漏装时用别名语法补：`npm i -g "@openai/codex-win32-x64@npm:@openai/codex@<版本>-win32-x64"`）。
- **切换前先平行验证**：同一批错题让它按 cuoti-fupan 的 SKILL.md 出一轮题，核对"不换壳"出题质量 + 判题是否贴《考试分析》原文、敢不敢说"查不到"。这两项过关整套就过关。

### B 档：低成本——开源 CLI + 国产模型
OpenCode / Crush 等开源 agent CLI（都读 AGENTS.md、能跑 shell 读写文件）+ GLM 编码包月（~¥20/月）或 DeepSeek API（~¥1-2/百万 token）。法硕是纯中文任务，国产模型在中文法律语料上最不吃亏。

### C 档：零成本 CLI
Qwen Code（免费额度 ~2000 次/天）或 iFlow 心流 CLI（免费接 Qwen/Kimi/DeepSeek，国内网络友好）。日常带背、复盘、周报够用；出题深度略降。

### D 档：最保底——网页版 + 手动跑脚本（不依赖任何工具）
人肉当 harness，闭环一步不缺：
1. 跑数据命令，如 `node --env-file=.env.local scripts/cuoti.mjs list`；
2. 把【SKILL.md 全文 + 命令输出 + `Claude记忆备份` 里相关画像文件】贴进网页版 DeepSeek/Kimi/GLM（免费）；
3. 模型出题/判题/写周报；
4. 按 SKILL.md 里写的写命令（absorb / log / save…）手动落库。

## 3. 恢复记忆（换任何 harness 的第一步）

把 `D:\fashuo\Claude记忆备份\` 整个目录喂给新模型（CLI 就让它读目录；网页版贴 MEMORY.md 索引 + 相关记忆文件）。没有这步，新模型等于不认识云的老师——判题会按白纸新手标准来，质量必掉。

> 你是云的法硕私人教练。先读这三样再干活：
> ① `D:\fashuo-app\AGENTS.md`；
> ② `D:\fashuo\Claude记忆备份\MEMORY.md` 索引，并按需读同目录下的记忆文件（重点：yun-ability-profile、yun-weakspot-exceptions、coach-judging-discipline、fashuo-only-no-fakao、cite-source-in-answers）；
