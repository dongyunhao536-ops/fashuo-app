# 法制史背诵论（带背教案）

> **背诵性质：纯记忆·"背多分"。** 命题最稳（史料引文 + 设问），主观题分值稳定（每年 1 简答 + 1 材料分析）。**口诀是主力武器**——探库实证：法制史 109 条 `【口诀】`，是云在用的 Anki《背诵宝典》真实口诀，带背照原文用。
> ⚠️ 对云性价比最高（纯记忆、不烧脑、命题稳），但**最容易"背了就忘"**——正撞他病根，**每周至少滚 3 次**是硬指标。

---

## 一、怎么背（法制史专属：双线织网）

同一考点两个维度都能挂上，考场无论从"哪朝"还是"哪个制度"切入都能定位：
- **朝代主线（纵）**：一朝一张卡（立法成就 + 司法制度 + 刑罚 + 特色）；
- **制度纵线（横）**：一个制度跨朝演变（五刑、会审、法典体例、婚姻继承、监察）。
- **口诀标《考试分析》页边**，后期对着口诀回忆整段；
- **隋唐、明清极高频优先**，冷门朝代混脸熟。

## 二、口诀锚（《背诵宝典》真实口诀·按朝代，隋唐明清重点）

**总纲**：中国传统法制特征 —【一诸自家处】

**西周**：礼的内容【吉凶军宾嘉】（五礼）｜主要刑法原则【老故疑中宜上同】｜六礼【采问吉征请迎】（纳采/问名/纳吉/纳征/请期/亲迎）

**秦汉**：秦法律形式【律令答诊廷】｜汉法律形式【律令科比】｜文景刑制改革【鼻子 321，左腿 532】（劓→笞三百→二百…）｜汉刑罚适用原则【上亲老】（上请/亲亲得相首匿/矜老恤幼）｜**春秋决狱**【心事附殊礼】

**三国两晋南北朝**：曹魏《新律》【18 具八革】｜晋《泰始律》【例简分注服】（法例篇/张斐杜预注/准五服）｜**北齐律**【体例十五明】（12 篇·法令明审科条简要·北朝最高成就）｜准五服以制罪【斩齐大小麻】（斩衰/齐衰/大功/小功/缌麻）｜八议【亲故贤能，贵宾勤功】｜旧五刑（墨劓刖宫大辟）→新五刑【缘公酷减】

**隋唐 ⭐⭐⭐（重点中的重点）**：
- 开皇律成就【体新十八】（体例新增十八…定型十二篇/十恶/五刑）
- 唐法律形式【律令格式】
- **唐律十二篇**【名卫职，户兴厩，贼斗诈，杂捕断】（名例/卫禁/职制/户婚/厩库/擅兴/贼盗/斗讼/诈伪/杂律/捕亡/断狱）
- 唐律特点：**一准乎礼**（"一准乎礼，以为出入，得古今之平"）
- 唐自首【区所长方彻】｜老幼废疾减刑【75 81 97】｜贵族官员特权【议、请、减、赎、当】

**宋元**：宋法律形式【宋敕例事】｜折杖法【笞徒流加反】｜宋中央司法机关【理刑御亲控审制推】（大理寺/刑部/御史台…）｜元《风宪宏纲》=监察立法

**明清 ⭐⭐⭐**：《大明律》七篇（按六部分篇·名例+吏户礼兵刑工）｜明大诰（朱元璋亲撰）｜会审制度（三司会审/九卿会审/朝审/秋审/热审）｜申明亭｜清末：钦定宪法大纲、大清新刑律、修律（更多口诀 `cuoti.mjs material` 拉，别编）

## 四、滚动节奏（法制史最关键）

- **每周至少滚 3 次**——五科里滚动频率最高（遗忘最快）；
- 后期**对着口诀回忆整段**（看到【名卫职户兴厩…】能默出唐律十二篇）；
- 材料分析题练"**看引文认制度**"的手感（给一段律典原文，判朝代 + 制度 + 评价）。

---

## 五、背诵易错（法制史专属：张冠李戴）

- **人物 ↔ 制度**：《法经》=李悝（非商鞅/韩非）；春秋决狱=董仲舒；"律法断罪皆当以法律令正文"=张斐。
- **朝代 ↔ 制度入律**：八议入魏律、官当入北魏/陈律、五服制罪入晋律、十恶正式确立于开皇律。
- **五刑演变别串**：旧五刑（墨劓刖宫大辟）→ 新五刑（笞杖徒流死）。
- **一字之差**：具法=定罪量刑通则、法例篇=晋律总则、北齐律"科条简要"=北朝最高成就。

## 六、理解层检验（带背怎么考）

- 给**口诀问展开**（【名卫职户兴厩贼斗诈杂捕断】→ 默唐律十二篇）、给**展开问口诀**；
- 给一段**史料引文**让云认朝代/制度（模拟材料分析题）；
- **朝代×制度对齐**：问"八议哪个朝代入律""五服制罪哪部律首立"；
- 追问**制度评价/影响**（唐律"一准乎礼"的历史地位）。

## 七、你的专属提醒

1. **背多分、性价比最高**——纯记忆、命题稳，是综合卷里最容易把分拿实的一科，**别因"靠后突破"就一直空着**（你现在几乎没启动）。
2. 第 1 轮先啃**隋唐（唐律疏议）+ 明清**两块极高频 + 其余混脸熟，后期滚熟。
3. **"每周滚 3 次"是硬指标**——正撞你"背了就忘 / 不复盘"病根，宁可每次滚得快、别隔太久从头背。
4. 口诀是你的主武器，但**串完谐音要能还原制度内容 + 会认引文**，别只剩一串顺口溜。
