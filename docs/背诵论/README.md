# 法硕五科背诵论 · 带背教案

> **定位**：给【带背功能】（`daibei-pc` skill）当**教案**用的背诵垂直方法论——比 [`docs/方法论/`](../方法论/) 的"背诵段"更深一层：每科**背什么/不背什么、怎么背、章节背诵优先级、口诀锚、滚动节奏、背诵易错、理解层检验、云专属**。
> **依据**：背诵经验帖（艾宾浩斯滚动/口诀/体系/冲刺节奏）+《考试分析》章节底座 + **Anki《背诵宝典》真实口诀** + 2014–2025 真题高频（定背诵优先级）+ 云画像病根。
> **配套**：通用背诵法见 `.claude/skills/daibei-pc/beisong-blueprint.md` 与 `docs/方法论/00_总纲`；各科整体打法见 `docs/方法论/`。
> ⚠️ **口诀纪律**：本系列口诀均摘自云在用的 Anki《背诵宝典》（真实、与他 rote 对齐）。**刑法/民法是理解型、口诀少**——需要口诀现用 `cuoti.mjs material` 从库里拉，**别凭空编**（[[cite-source-in-answers]]）。

## 带背功能怎么用这套

1. 带某科某章前，先读该科背诵论 + `beisong-blueprint` 的章节底座 → 定"背什么、怎么背、优先级"。
2. **给骨架 → 让云用自己的话复述/白纸默框架**（理解层，不是逐字默——逐字归 Anki）。
3. 纠错必 `material` 贴《考试分析》原文；口诀照《背诵宝典》原文，别改写。
4. 背诵栽点进"背诵易错点台账"（[[recite-mistakes-tracking]]），每次开场复检、改对一次不算过关。
