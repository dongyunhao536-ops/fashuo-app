## 0. 先认清你是谁——方法论必须为"你的病根"服务

- **画像**：在职、五战、非法学、目标北大 375+。有基础，不是新手。
- **病根（你自述 + 经验帖里失败者的共性，三条完全吻合）**：① 启动晚　② 从不复盘　③ 重复犯老错。
- **弱项特征**：强在识别/分类/决策树，**弱在"原则的例外与边界"**（中止自动性、法条竞合重法优先例外、法不溯及既往的刑法例外……凡"原则+例外"成对的地方最容易栽）。
- **审题老毛病**：容易被"构成""特别"这类字眼勾走，答非所问 / 只答一半。

> **由此定死方法论优先级（铁律，五科通用）：**
> ## 复盘　＞　错题闭环　＞　模考节奏　＞　进度铺开
> 对五战的你，"把学过的坑填平、错题不二过"比"多铺两章新的"值钱得多。**这是你和前四次的唯一区别点。**

## 1. 试卷结构与 375 分倒推（决定时间投到哪）

| 卷 | 构成 | 题型（2018 年后） |
|---|---|---|
| **专业基础 150** | 刑法 + 民法 | 单选 40×1 + 多选 10×2 + 简答 4×10 + 法条分析 2×10 + 案例 2×15 |
| **综合 150** | 法理 + 宪法 + 法制史 | 单选 40×1 + 多选 10×2 + 简答 3×10 + 分析 3×10 + 论述 2×15 |

- **选择题两卷共 120 分**——**性价比最高的拿分点**，目标拿 95+。死磕 12 年真题、错题反复，这是 375 的地基。
- 主观题（简答/法条/分析/案例/论述，两卷共 180 分）靠**答题结构规范 + 踩点**，目标 130+。
- **北大只看总分 + 单科不能太低**（专业课全国统考、题目全国统一）。所以策略 = **客观题刷透 + 主观题踩点规范化**，不需要押题、不需要偏难怪。

**命题新趋势（近 3 年，五科都要吃住）**：
1. **案例愈发"叠层"**——一道题考 3–5 个点，先逐行为定性再判罪数（刑法尤甚）。
2. **法条分析考"解释能力"**——不只背要件，考术语内涵、同款不同情形、立法理由。
3. **紧扣立法热点**——刑修十二、民法典新制度、监察法、备案审查、生态文明入宪等。
4. **综合卷强调"思政方向"**——习近平法治思想、良法善治、中华优秀传统法律文化。

## 3. 通用方法（五科共用，学科分篇只写"差异与重点"，此处不重复）

**① 听课**：理解工具，不是电视。刑民**可听**（把逻辑听通），法综**少听多背**（尤其法史/宪法，听课性价比低）。听完必须自己复述/默框架，否则=白听。

**②《考试分析》= 唯一圣经**：99% 答案在里面，法综尤其以它为准。目标 **12+ 遍**（滚动、不是一次读完）。一切口诀/高频/原文表述以它为准，别被外部框架带偏。

**③ 背诵（通用四原则，各科差异见分篇）**：
- **理解 1–2 遍再背**，否则无效背诵；
- **框架先行再填肉**——白纸默画章→节→考点骨架，能默出＝过关线；别一字不差（"背书强迫症"是坑）；
- **重复 > 单次时长**（5 分钟×3 胜 15 分钟×1），**必须滚动复背**（艾宾浩斯节点：5min/30min/12h/1d/2d/4d/7d/15d）；
- **单科推进**，别五科并行背到处夹生；难点编口诀。

**④ 做题**：
- **真题 2–3 遍**：第一遍分章配学习进度、第二遍成套找命题规律、冲刺再滚错题；
- **选择题**：死磕真题、错题反复，是 120 分的基本盘；
- **主观题**：无论问不问，**第一步先写概念**（《考试分析》原文口径），再**分点作答**，让阅卷人一眼找到得分点。

**⑤ 复盘闭环（你的命根，五科盯死）**：错题 → 定位到《考试分析》具体章节 → 回原文补漏 → 记错题本 → **下周滚动复检**。订正过仍重复错的，说明没真懂，转专题抠。

**⑥ 模考**：不可缺（失败者共性）。没定期模考 → 考场时间分配崩、大题写不完。9 月底起进入模考节奏。

**⑦ 背诵栽点 ≠ 错题**：带背/背诵过程中默错、记不清的点，单独进"背诵易错点台账"（每次带背开场复检、改对一次不算过关），**不进错题本**（错题本只装做题错题）。
