# 英语一方法论（云专用 · 2026-07-10 建）

> 定位：公共课第二战场。底子 70、目标 75+。只打两块：**阅读提准 + 作文从零到均分以上**。
> 完形/新题型/翻译不做专项，12 月成套模考顺带练——这三块投入产出比低，云底子够用。
> 与专业课方法论的最大不同：英语没有《考试分析》这样的圣经，**真题本身就是圣经**——
> 所有规律从 `.local/英语真题/` 十年真题里来，不引机构口号。

## 一、云的病根诊断

"读得懂但选不对、感觉哪个都对"——这不是阅读能力问题，是**选项判别标准缺失**：
他用"和文章印象吻合度"选答案，而出题人恰恰针对这个造干扰项。四个选项都"沾边"，
沾边程度还差不多，靠印象必然抓瞎。与他专业课"措辞精度弱"（应当/可以、原则/例外）同一个病根。

**叠加病根（7-10 补充）：凭语感做题 + 长难句语法不擅长**。语感本身是资产（70 分就是它挣的），
问题在语感没有置信度分级——短句上可靠，长难句上给出的是模糊印象、可信度骤降但自信不降。
而出题人最爱把答案藏在长难句的修饰边界、指代、让步转折里，专收"大意读对了、细节读糊了"的分。
对策**不是上语法课**（在职+70 底子，系统语法课 ROI 极低），而是"真题句内修"：
每道错题/犹豫题的定位句若是长难句，做"主干—修饰—指代"三行拆解（谁-做了什么-修饰语管到哪个词为止），
每篇另精析全文最难 1 句。三个月下来考研反复考的那几种句型（分隔结构/多重后置定语/让步-转折嵌套/
虚拟与倒装/比较结构省略）就在他手里过了几十遍，比语法书快得多。

**药方＝换判别标准**：从"哪个读着顺"换成"哪个能在定位句找到逐词对应的改写"。
核心律：**正确项 ≈ 定位句的同义改写（paraphrase）；干扰项 ≈ 原文原词的重新组装**。
出题人用原词钓"印象派"考生，用改写藏正确项。云要练的是见到原词复现先警惕、
见到改写先验证，每题都问"这个选项的每个词，定位句里对应哪个词"。

## 二、阅读做题流程（精刷期固定动作）

1. **先读题干（不读选项）**：圈定位词（专名/数字/引号词优先），预判题型。
2. **顺段落做题**：英语一命题基本按段落顺序（一题一两段），读到哪做到哪，别通读全文再做。
3. **找定位句**：题干定位词回原文锁 1–2 句，**答案必须出自定位句及其前后一句**，出圈的选项再顺眼也不选。
4. **选项四选一走排除**：每个选项标"改写/原词复现/无中生有"，两项犹豫时比对定位句逐词验证，**谁多出一个原文没有的程度词/范围词谁死**。
5. **对完答案逐题归因**（对的也归）：错题+犹豫题归到下面税目表，报套路名。

## 三、干扰项套路税目表（判别用 · 云背下来）

**题型五类**：细节题（据题干定位）/ 推理题（infer/suggest/imply）/ 主旨标题题 / 态度题 / 词义句意题。

**干扰手法八条**（错题归因就用这些名字）：
1. **过度推理**：原文 may/some/tend to → 选项 must/all/certainly；或把"A 发生了"推成"A 导致 B"。推理题第一杀手——英语一的"推理"只推半步，推两步就是错项。
2. **偷换概念**：定位句主语/宾语/限定范围被悄悄换掉（"部分学者认为"→"学界共识"；"英国的做法"→"欧洲的做法"）。
3. **张冠李戴**：观点 A 的内容安到 B 头上；作者观点和被批评者观点对调（尤其态度题、例证题）。
4. **无中生有**：选项每个词都眼熟，但拼出的命题原文根本没说——原词复现钓鱼的典型形态。
5. **答非所问**：内容是对的（原文确实说过），但不回答这道题干——细节题第二杀手，专钓"读得懂"的考生。
6. **正话反说**：加不加否定词、褒贬色彩反转（态度题里 approval ↔ skepticism）。
7. **以偏概全**：拿一段的意思冒充全文主旨（主旨题）；或拿例子冒充观点（例证题问"为什么举例"，答案永远在例子前后的观点句，不在例子本身）。
8. **拼写近义陷阱**：词义题给一个"认识的意思"，但该词在此语境是别的义项——词义题答案永远是语境义，代回原句验证。

**态度题小抄**：考研作者态度 90% 是"有保留的批评/有保留的支持"（critical / skeptical / cautiously optimistic / objective），极端项（indifferent / totally negative / enthusiastic）基本是错项。

## 四、作文（30 分 · 从零到 20+）

**评分档（判卷口径）**：大作文 20 分四档——17–20（一档：内容完整+语言丰富+结构清晰+错误极少）/ 13–16（二档：内容较完整+语言较准确+少量错误）/ 9–12（三档：内容基本相关+错误较多但可读）/ ≤8（四档）。小作文 10 分对应折半。**云的目标：大作文稳 14+、小作文稳 7+**。

**打法＝个人模板迭代法**（不背市售通用模板——判卷人见过一万遍，撞车即三档）：
1. 每篇批改只修 **3 个最伤分的病根**，下篇验收上篇的修正。
2. 修好的句子进 `.local/英语作文语料.md`，按功能分格子：图画描述 / 首段点题 / 意义论证 ×2 / 举例 / 建议结尾；小作文：称呼+首段套件 ×（建议信/邀请信/通知/介绍信）。
3. 11 月底把语料库长成**云自己的模板**：大作文三段框架每段 2–3 个他写熟的句型，考场只换主题词。
4. 大作文题型对策：英语一是**图画作文**，十年题材全是抽象品质类（坚持/合作/自信/乐观/传承），首段描述图画 2 句 + 点出寓意 1 句是死格式，先把这 3 句练到条件反射。

**小作文**：格式分占一半——称呼、落款、语域（正式/半正式）别丢分；十年考过：推荐信/建议信/邀请信/通知/介绍信，每类备一个 4 句骨架即可。

## 五、十年命题趋势（据 2016–2025 题库归纳）

- **题材**：社科评论为主（教育/劳动市场/科技伦理/环保政策/文化产业），2022 起明显加码**科技与社会**（AI 绘画、数字保存、流媒体、零工经济、数字税）。生态环保稳定一篇上下（森林/湿地/碳排放）。**没有硬科技和纯文学**——都是《卫报》《经济学人》《大西洋月刊》式的公共议论文。
- **难度结构**：文章读起来越来越平易，**选项区分度全压在措辞精度上**——正对云的病根，也正是"感觉哪个都对"的来源。近三年推理题和例证功能题占比上升，细节直取题下降。
- **作文**：大作文十年未变图画作文+品质主题；小作文近年偏应用场景（通知/介绍中国文化给外国友人）。
- **对策含义**：精刷时按套路归因比按题材归因有用（题材不重复，套路年年重演）；作文品质词表（perseverance / cooperation / confidence / innovation / inheritance）提前备好论证语料。
