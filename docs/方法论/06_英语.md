# 英语一方法论（云专用 · 2026-07-10 建）

> 定位：公共课第二战场。底子 70（高考 123/150）、**目标 75**（2026-07-31 定档，唯一事实源＝`config/coach.json` 的 `目标分`；带硬条件：若 9-26 模考时仍近乎零流水则降回 72）。只打两块：**阅读提准 + 作文从零到均分以上**。
> **75 的拆法＝阅读 34（错≤3）+ 作文 22 + 完形 6 + 新题型 7 + 翻译 6**。"争 80"已评估未采纳，理由见 config `_英语上修注`。
> 完形/新题型/翻译不做专项，12 月成套模考顺带练——这三块投入产出比低，云底子够用。
> 与专业课方法论的最大不同：英语没有《考试分析》这样的圣经，**真题本身就是圣经**——
> 所有规律从 `.local/英语真题/` 十年真题里来，不引机构口号。

## 一、云的病根诊断

"读得懂但选不对、感觉哪个都对"——这不是阅读能力问题，是**选项判别标准缺失**：
他用"和文章印象吻合度"选答案，而出题人恰恰针对这个造干扰项。四个选项都"沾边"，
沾边程度还差不多，靠印象必然抓瞎。与他专业课"措辞精度弱"（应当/可以、原则/例外）同一个病根。

**叠加病根（7-10 补充）：凭语感做题 + 长难句语法不擅长**。语感本身是资产（70 分就是它挣的），
问题在语感没有置信度分级——短句上可靠，长难句上给出的是模糊印象、可信度骤降但自信不降。
而出题人最爱把答案藏在长难句的修饰边界、指代、让步转折里，专收"大意读对了、细节读糊了"的分。
对策**不是上语法课**（在职+70 底子，系统语法课 ROI 极低），而是"真题句内修"，每篇另精析全文最难 1 句。

### 长难句：「切碎—认主—念荒谬」三步（2026-07-30 定 · 零语法名词）

**起因**：2026-07-30 首篇精刷（2016 Text 1）云 5/5 全对，但第 2 段末句
`It tells the fashion industry that it must take responsibility for the signal it sends women, especially teenage girls, about the social tape-measure they must use to determine their individual worth.`
他读成"必须对女性健康负责"——`健康`这个词整句没出现，是从上半段搬来的。教练用"定语从句／插入语／修饰语归属"三行拆解讲完，**云明确反馈无效**：「我的语法理论知识不太好，从小都是靠预感，你得采取点特别的方式」。
→ 术语型讲解对他是空转。原三行拆解法（主干—修饰—指代）**作废**，改下面三步。

**① 切碎**——见到 **逗号 / 介词（about, of, for, in, with）/ that, which, who / to do** 就下一刀，切到每块都短得一眼能懂。
> 这一步的全部意义：**把长句砍成短句，让他可靠的那半边语感重新上岗**。不是替换语感，是给语感创造能工作的条件。

**② 认主**——每个碎块只问一句「**你在说前面哪个词？**」。不问它是什么从句、不要求命名。

**③ 念荒谬**——把碎块塞回它认领的那个词后面，**念一遍中文**。荒谬的就是认错主人，通顺的才对。
> 示例：`about the social tape-measure` 挂 responsibility → "对一把社会尺子负责"＝荒谬；挂 signal → "关于社会尺子的信号"＝通顺。**选通顺的那个，全程一个语法名词都没用。**

**教练侧纪律**：让云自己切、自己认主，**教练只在第③步给两个候选让他念**，不代切不代认。
**使用纪律**：**只对定位句用、一篇最多 2–3 次**——每句都切，18 分钟跑不完。

三个月下来考研反复考的那几种句型（分隔结构/多重后置定语/让步-转折嵌套/虚拟与倒装/比较结构省略）
就在他手里过了几十遍，**而且过的是"念着荒不荒谬"的手感，不是术语**，比语法书快得多。

**药方＝换判别标准**：从"哪个读着顺"换成"哪个能在定位句找到逐词对应的改写"。
核心律：**正确项 ≈ 定位句的同义改写（paraphrase）；干扰项 ≈ 原文原词的重新组装**。
出题人用原词钓"印象派"考生，用改写藏正确项。云要练的是见到原词复现先警惕、
见到改写先验证，每题都问"这个选项的每个词，定位句里对应哪个词"。

## 二、阅读做题流程（精刷期固定动作）

1. **先读题干（不读选项）**：圈定位词（专名/数字/引号词优先），预判题型。
2. **顺段落做题**：英语一命题基本按段落顺序（一题一两段），读到哪做到哪，别通读全文再做。
3. **找定位句**：题干定位词回原文锁 1–2 句，**答案必须出自定位句及其前后一句**，出圈的选项再顺眼也不选。
4. **选项四选一走排除**：每个选项标"改写/原词复现/无中生有"，两项犹豫时比对定位句逐词验证，**谁多出一个原文没有的程度词/范围词谁死**。
5. **对完答案逐题归因**（对的也归）：错题+犹豫题归到下面税目表，报套路名。

## 三、干扰项套路税目表（判别用 · 云背下来）

**题型六类**（按十年 200 题实际占比排序）：细节题 58%（据题干定位·含伪装成 "can be learned" 的间接细节）/ 推理题 11.5%（infer/imply/be concluded）/ 主旨结构题 10.5% / **例证功能题 9.5%（is mentioned/cited/quoted to·独立一类，答案永在例子前后的观点句）** / 态度题 7.5% / 词义句意题 3%（六年未考·最低优先级）。

**干扰手法八条**（错题归因就用这些名字）：
1. **过度推理**：原文 may/some/tend to → 选项 must/all/certainly；或把"A 发生了"推成"A 导致 B"。推理题第一杀手——英语一的"推理"只推半步，推两步就是错项。
2. **偷换概念**：定位句主语/宾语/限定范围被悄悄换掉（"部分学者认为"→"学界共识"；"英国的做法"→"欧洲的做法"）。
3. **张冠李戴**：观点 A 的内容安到 B 头上；作者观点和被批评者观点对调（尤其态度题、例证题）。
4. **无中生有**：选项每个词都眼熟，但拼出的命题原文根本没说——原词复现钓鱼的典型形态。
5. **答非所问**：内容是对的（原文确实说过），但不回答这道题干——细节题第二杀手，专钓"读得懂"的考生。
6. **正话反说**：加不加否定词、褒贬色彩反转（态度题里 approval ↔ skepticism）。
7. **以偏概全**：拿一段的意思冒充全文主旨（主旨题）；或拿例子冒充观点（例证题问"为什么举例"，答案永远在例子前后的观点句，不在例子本身）。
8. **拼写近义陷阱**：词义题给一个"认识的意思"，但该词在此语境是别的义项——答案永远是语境义，代回原句验证。
   ⚠️ **优先级最低·不专项练**：词义题 **2020 年起连续六年一题未考**（十年仅 6 题、占 3%）。记住上面这一句认知即可，别在 17–18 分钟里为它分配时间。

**态度题小抄**：考研作者态度 90% 是"有保留的批评/有保留的支持"（critical / skeptical / cautiously optimistic / objective），极端项（indifferent / totally negative / enthusiastic）基本是错项。

**两条补充判据（2026-07-19 经验帖综述带回 · 详见 `docs/英语经验帖.md`）**
- ✅ **跨段/跨句拼词判据**：选项里的词若来自原文**不同句子甚至不同段落**的拼凑，基本是干扰项（归税目 ③张冠李戴 / ④无中生有）。
  **本地实证**：`2016-T1-Q24[B]` 的 `character` 来自 Para 3 作者对大众说的正面话，被搬来当"设计师被 CFW 拒的理由"。外部经验帖与本地真题在这条上独立吻合，可信度最高。
- ⚠️ **语气判据（只作第二判据，禁止单用）**：正确项措辞常保守（can / may / might / some / not necessarily），绝对化词（must / all / never / certainly）多为错项——这是税目 ①过度推理的反面。
  **纪律：必须先回定位句逐词核对，两项难分时才用语气加权。单靠语气选＝把"凭感觉"换了个壳，正撞云的病根。**

**❌ 禁用清单（经验帖里的玄学，讲题时绝不引用）**
- 「选项含 approach / concept / chance / various / both / general / many 等词即为正确答案」——纯词表迷信，无机制，会把云的病根伪装得更深。
- 「背一套万能模板保底 22 分」——判卷人见过一万遍，撞车即压三档。
- 检索到的图表作文资料**大量是英语二的**，英语一 ≠ 英语二，引用前必须核对卷别。

## 四、作文（30 分 · 从零到 20+）

**评分档（判卷口径）**：大作文 20 分四档——17–20（一档：内容完整+语言丰富+结构清晰+错误极少）/ 13–16（二档：内容较完整+语言较准确+少量错误）/ 9–12（三档：内容基本相关+错误较多但可读）/ ≤8（四档）。小作文 10 分对应折半。**云的目标：大作文稳 14+、小作文稳 7+**。

**打法＝个人模板迭代法**（不背市售通用模板——判卷人见过一万遍，撞车即三档）：
1. 每篇批改只修 **3 个最伤分的病根**，下篇验收上篇的修正。
2. 修好的句子进 `.local/英语作文语料.md`，按功能分格子：图画描述 / 首段点题 / 意义论证 ×2 / 举例 / 建议结尾；小作文：称呼+首段套件 ×（建议信/邀请信/通知/介绍信）。
3. 11 月底把语料库长成**云自己的模板**：大作文三段框架每段 2–3 个他写熟的句型，考场只换主题词。
4. **背诵口径：先写后背，背的只能是他自己的句子**（2026-07-30 云问"素材要背么、范文要不要背"定档）——
   - **语料库里的 🌱 种子句不背**。种子句是我给的启动模子，背它＝背我的模板，与背市售万能模板同一个下场（判卷人见过一万遍，撞车即三档）。顺序永远是**写 → 我改 → 标 ✅ → 背 ✅ 那批**，11–12 月背成型的 15–20 句。
   - **范文整篇不背，只当拆件场**。三条理由：云的病根是"没写过"不是"没见过好句子"，背进去调不出来；市售范文撞车风险与模板同级；一篇 200 词能挪进考场的顶多 3 句。正确用法＝挑 2–3 个句式骨架填进语料库对应格子，与从阅读原文薅 D3 是同一个动作。**唯一值得整篇背的范文＝他自己写熟、我改过的那篇终稿**（12 月默写的就是它）。
   - **各格子档位不同，别一刀切**：E1 小作文格式（`Yours sincerely` + `Li Ming`、NOTICE 居中、不写地址）**现在就背死**，是全库唯一该 rote 的——格式分白送；D1/D2 主题词**不背**，眼熟、写时查得到即可（词是弹药不是句子）；A/B/C 句型与 D3 薅来的骨架**只攒不背**，等云写出自己版本再进背诵池。
5. **大作文题型对策＝两套载体都要练**（2026-07-19 据十年真题逐卷核对修正，原写"十年未变图画作文"是错的）：
   - **漫画型**（2016–2023 主力）：描述画面 2 句 + 点出寓意 1 句，死格式，练到条件反射。
   - **图表/表格型**（2024 漫画+柱状图、2025 纯表格，连续两年）：总述数据对象与时间跨度 1 句 + 报起止数值 1 句 + 概括趋势 1 句，然后**解读成因**（图表作文真正的得分手，不是描述）。趋势词要分级：surge / climb steadily / rise moderately / edge up / level off。
   - **只练漫画＝赌 2026 不考图表，赌输就是三档**。两套首段同等投入。
   - **题材重心已从"个人品质"漂向"社会民生/文化/数据"**（2023 龙舟传承、2024 城市公园、2025 居民消费品）——品质词表不够用，须另备社会发展类语料（living standards / urban renewal / cultural heritage / rural revitalization / public well-being）。
   - 逐年题目全表见 `.local/英语真题/作文十年题库.md`。

**小作文**（十年逐卷核对结果）：文体分布＝**邮件 7 次**（推荐 2017 / 邀请 2018·2022 / 回复咨询 2019 / 建议 2021 / **回信 2024·2025**）> **通知 3 次**（2016·2020 / 招聘启事 2023）。
- **格式分白送别丢**：称呼、`Yours sincerely` + 一律落款 **Li Ming**、**不写自己名字、不写地址**（十年重复的显性要求）；通知另需标题 `NOTICE` + 落款单位。
- **打法＝要素 checklist，不是套模板**：几乎每年 directions 里明写"须包含"（2017 理由 / 2018 时间地点 / 2019 项目细节 / 2023 职责+任职要求）——审题先圈成清单，写完逐条核对。这是小作文最高 ROI 的动作。
- **2024 起变成"读来信→写回信"**（题干直接给出 Paul 的原邮件），**必须逐条回应来信里每一个问题**（2025 是两问：展示什么 + 我能帮什么）。**套通用模板最容易漏问，漏一问即硬伤**——这是当前小作文第一优先级。

## 五、十年命题趋势（据 2016–2025 题库归纳）

- **题材**：社科评论为主（教育/劳动市场/科技伦理/环保政策/文化产业），2022 起明显加码**科技与社会**（AI 绘画、数字保存、流媒体、零工经济、数字税）。生态环保稳定一篇上下（森林/湿地/碳排放）。**没有硬科技和纯文学**——都是《卫报》《经济学人》《大西洋月刊》式的公共议论文。
- **难度结构**：文章读起来越来越平易，**选项区分度全压在措辞精度上**——正对云的病根，也正是"感觉哪个都对"的来源。
- **题型分布（2026-07-19 全 200 题逐题统计修正，明细见 `.local/英语真题/阅读题型十年统计.md`）**：
  - 细节题 **58%（116/200）是绝对主力**——原写"细节直取题下降"**是错的**，2021–2023 反而是十年高位。真实变化是**"直取变间接"**：题干从 "According to Para 2" 变成 "What can be learned about X"，**披着细节皮的推断**。定位句纪律不能松。
  - 推理题上升属实，但**拐点是 2020 不是"近三年"**：2016–2019 年均 1.25 题 → 2020–2025 年均 3 题。
  - 例证功能题 2017 起年年有、近五年稳定 2–3 题，**规律最硬**（答案永远在例子前后的观点句），性价比最高。
  - **主旨题会整年消失**（2022、2023 连续两年 0 题，连 best title 都没有），态度题 2021 年 0 题——**别用"每篇总该有道主旨题"的惯性倒推答案**（云的审题惯性病根在此最易发作）。
- **作文（2026-07-19 逐卷核对修正）**：大作文**2023 是分水岭**——2016–2022 漫画+个人品质，2023 转社会/国情题材（龙舟赛），2024 混入柱状图，2025 直接给纯表格。**图表型已连考两年，2026 概率不低于漫画型**。小作文 2024 起变"读来信→回信"，须逐问回应。
- **对策含义**：精刷时按套路归因比按题材归因有用（题材不重复，套路年年重演）；作文语料**分两栏备**——个人品质类（perseverance / cooperation / confidence / innovation / inheritance，老题材仍可能回归）+ **社会民生文化类**（living standards / urban renewal / cultural heritage / rural revitalization / public well-being，2023–2025 新重心、云的空白区），另加**图表趋势词分级表**。
