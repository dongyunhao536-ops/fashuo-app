## 状态枚举

- `吻合`：独立证据与旧结论一致；
- `冲突`：同一命题的结论不同；
- `无法证实`：现有材料不足以支持旧结论；
- `来源层级错误`：结论可能成立，但原先引用的来源不能承担该证明；
- `版本待核`：答案受法律、教材或命题年份变化影响；
- `已修复 / 已隔离 / 处理中 / 待处理`：工程处置状态。
