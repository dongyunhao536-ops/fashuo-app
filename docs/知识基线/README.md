# Codex 独立知识基线

> 建立日期：2026-08-04（北京日）
> 状态：第一阶段完成，第二阶段（教材段级 provenance / 法律更新 / Anki）待启动
> 目标：不抹掉既有学习历史，以原始资料重新校准考试知识，并把结论沉淀为可检索、可追溯、可增量更新的资产。

## 1. 三条总原则

1. **知识结论独立复核**：Claude 历史记忆、现有方法论和 skill 都是“待审资产”，不能仅因已经写入项目就自动成为正确答案。
2. **用户历史继续继承**：云的真实错题、带背挂账、主观题表现、长期约定不能从教材里重新推导，必须保留；当前状态始终现查 Supabase、`.local/` 和 `config/coach.json`。
3. **不制造第二套大摘要**：按章、按题沉淀原子结论和差异；每条带来源、行号、版本和信心度。一次性读入上下文不算完成。

## 2. 来源等级

| 等级 | 来源 | 用法 |
|---|---|---|
| S0 | 能确认属于五科《考试分析》正文的段落、真题题干 | 考试知识的首要事实源；结论必须能回到具体路径和行号。重排/彩标文件里的机构附边不能因同文件而自动升为 S0 |
| S1 | 随卷参考答案与解析、现行法律更新档案 | 判题与版本校准来源；保留“答案提供方/版本是否明确”的出处标签，不把所有解析笼统称为官方 |
| S2 | 刑法、民法、法理、法制史讲义原文及作者标注框 | 帮助理解与辨析；与 S0 冲突时以 S0 为准，并登记差异 |
| S3 | 手动做题心得、易混概念库、Anki 背诵资料 | 个性化检索线索；必须能回连 S0/S1/S2，手动实证可高优先但不替代原文 |
| S4 | 真题趋势总结、方法论、skills、Claude 历史记忆、模型生成总结 | 待验证的派生资产；用于提出假设，不单独承担事实裁判 |
| 状态层 | `study_log`、`study_error`、`coach_memory`、`.local/`、`config/coach.json` | 只回答“云现在学到哪、错在哪、定过什么”；不得静态抄进教材结论 |

## 3. 验收红线

- 每条校准结论至少包含：`source_level`、源路径、真实行号或题号、资料版本、复核状态。
- “不存在、未收录、没有答案、已经过时”等否定性断言必须用第二种口径复查。
- 真题频次、题型趋势和章节权重只能由全量结构化题库计算；模型印象不能报成统计事实。
- 题干、答案、解析三者分字段保存；题干汇总不能冒充答案库。
- 可能留作模考的近年净卷不得把题干输出到校准报告或日常提示中；内部索引只保留元数据和封存标记。
- 新版教材、新年度真题或法律更新进入后只做增量差异，不重新覆盖全部历史。
