## 一、阅读：与本地真题实证**对得上**的（✅ 直接采信）

- ✅ **"选项由原文不同句子/不同段落的词拼凑而成 → 干扰项"**（源 1、3）。
  → **本地实证**：`2016-T1-Q24[B] caring too much about models' character` —— `character` 来自 Para 3 作者对大众说的正面话，被跨段搬来当"设计师被 CFW 拒绝的理由"。
  与税目 ③张冠李戴 / ④无中生有完全吻合。**这条是外部经验帖里质量最高的一条**，已进税目表。
- ✅ **"正确项＝原文的同义替换；再现原文原词的多为干扰"**（源 1、4）。
  → 与方法论核心律"正确项 ≈ 定位句同义改写；干扰项 ≈ 原词重新组装"一致，**外部独立佐证成立**。
  本地实证：`2016-T1-Q23[B]` 用 `inherent problem` 原词复现钓鱼。
- ✅ **"正确项措辞常带不确定/保守语气（can / may / might / some / not necessarily）；绝对化词多为错项"**（源 1）。
  → 这是税目 ①过度推理的**反面表述**，机制成立（出题人用绝对化造错项）。
  ⚠️ 但**只能当第二判据**：先回定位句逐词核对，语气特征只用于两项难分时的加权。**单靠语气选答案＝换了个壳的"凭感觉"**，正撞云的病根。
- ✅ **"先读题干划关键词（专名/数字/核心名词）→ 回原文定位 → 比对选项"**（源 2、3、5）。
  → 与方法论做题流程一致，无冲突。

## 二、阅读：需裁剪的（⚠️ 改造后用）

- ⚠️ **"真题至少刷三遍（一遍精翻／二遍总结技巧／三遍重做难篇）"**（源 4、6、8）。
  → **云不能照搬**：在职双轨、英语是第二战场、底子已 70 分。**"精翻每个句子"对 70 分底子是低 ROI**（那是给基础薄弱者的处方）。
  → **云的裁剪版**：一遍精刷（做题+归因+句内修长难句，不逐句精翻）；11 月**只二刷高错篇目**；三刷取消。
  与 `06_英语.md` §六 日程轴一致。
- ⚠️ **"6 月前单词过一遍 → 7 月精读 → 8 月精做 → 9-10 月写作文 → 11-12 月查漏"**（源 9）。
  → 时间轴大方向可参考，但**云的作文启动不能拖到 9 月**（他作文零准备、30 分裸考，是最大增量）。
  已在方法论里前移到 **7–8 月轻启动攒语料**。

## 三、阅读：明确不采信的（❌ 玄学）

- ❌ **"选项中含 approach / concept / chance / opportunity / various / both / general / many / difficult / way / necessary / importance 等词的是正确答案"**（源 1）。
  → **无任何机制支撑**，纯词表迷信。若云信这个，等于把"凭印象选"换成"凭词表选"，**病根不但没治还更隐蔽**。
  → **禁止在讲题中引用此类词表。**
- ❌ **"背一套万能模板保底 22 分"类作文模板贴**（检索中大量出现，如"26考研英语一作文模板（保底22分）"）。
  → 与 `06_英语.md` 的判断冲突：判卷人见过一万遍通用模板，**撞车即压三档**。
  → 云走**个人模板迭代法**（`.local/英语作文语料.md`），不背市售模板。
- ❌ **"英语二图表作文万能模板可直接背诵"**类（源检索结果中多为英语二内容）。
  → **英语一 ≠ 英语二**，题材与评分档不同。检索时大量图表作文资料是英语二的，**引用前必须核对是英语一**。

## 四、作文：外部佐证与本地发现的**互相印证**（✅ 重要）

- ✅ **图表作文三段论：①描述数据 ②解释原因 ③总结/建议**（源 10）。
  → 与本地十年题库发现（2024 图+柱状图、2025 纯表格）**正好接上**，且经验帖强调
  **"第二段原因怎么写得不敷衍，是阅卷老师关注的重点"** —— 与我判断的"**解读成因才是图表作文的得分手，描述不是**"独立吻合。
  → 已进 `.local/英语作文语料.md` B 组（B1 数据描述 / B2 成因解读）。
- ✅ **图表分两型：动态图（数据随时间变化，描趋势）／静态图（同期不同对象对比，描占比）**（源 10）。
  → **本地实证**：2025 纯表格（2014/2017/2020/2023 四档）＝**动态图**，描趋势；2024 柱状图（2020/2021/2022 公园数）也是**动态图**。
  → **含义：近两年考的都是动态图，趋势词分级（surge/climb steadily/rise moderately/edge up/level off）是刚需**，已进语料库 B1。
- ✅ **"只背范文写不出作文——先自己整理写作思路和模板，把话题分类、不同话题积累不同语料"**（源 7、11）。
  → **与个人模板迭代法完全一致**，且佐证了语料库**按话题分栏**的设计（D1 个人品质 / D2 社会民生文化）。
- ⚠️ **"遇到作文题先用中文思维分析，再把中文译成英文"**（源 7）。
  → 对零准备者是**可用的启动拐杖**，但**有中式英语风险**。
  → 云的用法：**只用于列提纲（中文列 3 个论点）**，句子层面直接调用语料库里已写熟的英文句型，**不做整句中译英**。

## 五、结论：这轮搜集对方法论的净改动

1. 新增 ✅ **"跨段/跨句拼词＝干扰项"**判据（外部提出 + 本地 2016-T1-Q24 实证）→ 已归入税目 ③④。
2. 新增 ✅ **语气保守词作第二判据**（明确降级为辅助，不得单用）。
3. 佐证 ✅ **图表作文"成因段才是得分手"** + **动态图趋势词分级** → 已进语料库 B 组。
4. 明确 ❌ **禁用正确项词表迷信 + 禁用市售万能模板** → 写进禁用清单，防云被带偏。
5. 裁剪 ⚠️ **"真题三刷/逐句精翻"** → 按在职 + 70 底子改为"一遍精刷 + 只二刷高错篇"。
