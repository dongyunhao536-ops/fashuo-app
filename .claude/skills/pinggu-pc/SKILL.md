# PC 备考评估（升级版 · 火力全开 · 全周期体检）

给云（在职·五战·目标北大 375+）做的**阶段性全面体检**：现在站在哪、离目标多远、照当前斜率外推能不能到、最大的窟窿在哪、接下来怎么办。区别于 weekly-pc 的周切面——这里看**全周期**，且必须**目标反推**（从 375+ 倒着算回来），不是顺着流水账夸进度。

## 数据采集（先跑齐再下笔，零编造）
1. **全账本**：`node --env-file=.env.local scripts/coach.mjs ledger`（距考天数/轮次/进度/错题/长期记忆/对话）。
2. **量化 v3（与 APP 今日页同一算法，别自己另编一套分）**：
   `npx -y tsx --env-file=.env.local -e "import('./src/lib/dashboard.ts').then(async m => console.log(JSON.stringify(await m.getDashboard(), null, 1)))"`
   → 综合备考指数（含最弱科×0.3 反偏科）、各科四维（广度/深度/背诵/闭环）、重犯数。算法依据见 `src/lib/dashboard.ts` 头注释（[[today-quant-v3-beida]]：minutes/accuracy 是故意排除的，别拿去当依据）。
3. **投入与吸收趋势**：`node --env-file=.env.local scripts/weekly.mjs data --week <周一>` 逐周跑近 3~4 周（每跑一次读走 `.local/weekly-data.json` 再跑下一周）——看学习动作数、复盘数、吸收数是升是降。
4. **错题本全量**：`node --env-file=.env.local scripts/cuoti.mjs list`（open 分布、复发🔁、科目集中度）。
5. **基准**：`config/coach.json`（轮次表/死线/红线：周投入下限 20h、9月底模拟 320、同弱项 3 次转专题）+ `docs/方法论/00_总纲`（阶段应达标什么）。

## 评估框架（六块，缺一块就不叫体检）
1. **一句话总评 + 红绿灯**：绿=按线走 / 黄=偏航可救 / 红=再不动就来不及。先给结论再给依据。
2. **硬数据面板**：综合指数、各科四维表、错题闭环（open/absorbed/重犯）、近几周投入趋势。数字全部来自上面采集，标注口径。
3. **进度审计（对照轮次表+死线）**：当前轮次窗口内**应**到位什么 vs **实**到位什么；未启动科目点名（民法/宪法/法制史哪科还是 0 就是 0）；距基础结业死线的剩余量倒推每周需要吃掉多少。
4. **病根追踪（用数据说话）**：启动晚 / 从不复盘 / 重复犯老错三条老病根 + [[yun-weakspot-exceptions]]"例外与边界"模式——哪条在好转（贴证据：复盘次数/闭环率）、哪条没愈（贴证据：重犯、模式 n）。
5. **目标反推（375+ 拆解）**：从分值结构（刑民各75、法理60、宪法50、法制史40、政英另算）+ 单科短板惩罚的含义倒推各科该到什么位；对照 9 月底模拟 320 红线，按当前斜率外推够不够、缺口多大。没有模拟考数据就如实说"无法校准，X 月必须模一次"。
6. **风险清单（按危险度排序）+ 行动处方（3~5 件）**：处方必须落到在职双轨具体时段 + 具体科目章节，带优先级；参考 `docs/方法论/` 各科打法，别泛泛"多背民法"。

## 铁律
- **零编造**：每个数字可溯源到采集步骤；数据缺失（如无模拟分、minutes 填充率低）如实说缺失本身，并把缺失当发现。
- **北大 375+ 严标准**：该泼冷水就泼（五战了，客气是害他），但差距必须翻译成"每周做掉多少"的可执行斜率，不许只吓唬不给路。
- **别把覆盖当掌握**：广度好看≠能力分高，四维里深度/背诵/闭环才是北大区分度——评估措辞跟着这个理念走。
- 纯法硕口径 [[fashuo-only-no-fakao]]；对话里给全文，同时存档 `.local/评估/pinggu-YYYY-MM-DD.md`（便于下次评估对照"上次体检说了什么、落实没"——**下次评估必读上一份**）。不写 APP 库（无对应表，要进 APP 展示另立项、需云点头）。

## 分工
- **weekly-pc**＝周报（本周切面、写 weekly_report 给 APP 展示）；**coach-pc**＝日常策略/规划/情绪；**cuoti-fupan**＝错题出题销账；本 skill＝**全周期体检**，产出留 PC 存档。评估里发现的弱项要考核→转 cuoti-fupan；要落到本周安排→转 coach-pc 口径。
