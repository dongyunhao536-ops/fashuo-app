含 P0 排期里的 `type=带背`。首题只需要主 Skill、本小节和当前教材／答案；不调用 `skill-context`，不预读蓝本全文、背诵论、完整运行参考、数据契约或记忆链接。材料冲突／当前教学确实缺方法时才定向补读，不能因文中出现链接就继续展开。已读内容仍在上下文时直接复用。

### 首题：建 Run → 一次取证 → Gate 连同 checkpoint

1. 用考试分析章·节作进度目标，运行 `node --env-file=.env.local scripts/skill-run.mjs start --skill daibei-pc --subject <科目> --kind progress --target "<考试分析章·节>"`。普通文本回执已给 Run ID，不需要 `--json` 的完整事件树。章节不明时只在本科教材查标题，不扫描全库。
2. 只查 `.local/带背标准答案.md` 的本专题。现役母版非选择题直接用主 Skill 的 `--template-entry` 快路径；没有母版则一次运行 `node --env-file=.env.local scripts/cuoti.mjs material-batch --query "<主题词>" --run <SR-ID>`。空格分开的词按同一行 AND 匹配，例如 `2018 宪法修正案` 同时匹配两本教材的年份写法；`--refine` 仅排序。命中片段截断时，只按返回路径／行号读取该专题完整正文一次，不换词重跑已成功检索。
3. 开场只组织“一小块讲解＋一道复述”。先解释条目关系，枚举超过四项就组块；按《考试分析》原序、标题与一句话内容教学，脚手架不混成标准答案。已知轮次沿用；未知时先作形成性学习，不判掌握、不挂错、不提前写进度，需判分前才定向核轮次矩阵。稳定复述单元首次判分前锁 A0；不为单个名词建模板，不把整节母版建完作为首段讲解前置。已核正文仍在上下文时不重复回源。
4. 无母版时，把已核过的首题答案写入 `.local/ak-<专题>.txt`，运行 `node --env-file=.env.local scripts/question-integrity.mjs check --type non-choice --stem "<一道题>" --answer-file <文件> --run <SR-ID> --checkpoint`；母版路径同样加 `--checkpoint`。只有 PASS 才展示同一题稿并等用户作答；不再单跑 checkpoint，不以未检查的讲解／题稿冒充放行。

达到“本小块原文完整、答案核准、题面 PASS”就开始教，不再为了整理背景或优化措辞继续读文件。下一块仍在同一章节 progress Run 中；单独点名专题不强插其他条目的开场冷检。第一轮订正、节末无提示总复述、应用锁扣和真实写回仍按主 Skill 执行，不因提速删除。

### 中断与收尾

- **没有 `resume` 子命令。** 同会话中断／换 turn 后，宿主已绑定原 Run 时直接给后续命令传原 `--run`；状态不明才查 `skill-run.mjs status --run <SR-ID>`。身份闸 BLOCK 就停，不自行改身份。Run 已结束才新建，不能复活旧回执。
- 用户改为诊断或修复流程：暂停教学，用 `skill-run.mjs abort --run <SR-ID> --source user --reason "<实际原因>"` 收原 Run；工程动作不建学习 Run、不记掌握结果。修复验证完再回到用户原定专题。
- 带完并完成总复述后：`node --env-file=.env.local scripts/coach.mjs log --run <SR-ID> --subject <科目> --activity 带背 --chapter "<同一章节>" --feeling "<真实覆盖＋效果＋撤梯级>"`，然后 `node --env-file=.env.local scripts/skill-run.mjs end --run <SR-ID> --phase progress --done response_verified --ref "<study-log 回执>"`。只带了专题不能冒记整节完成；同节只写一条真实汇总。
