## 零、这份清单是怎么算出来的（口径 + 三处已知失真，别当黑箱用）

**两个独立源交叉，冲突时以真题原文为准：**

1. **真题原文**（主源）：`D:\fashuo\真题\_文本\` 2014–2025 共 **12 套专业基础卷（非法学）**，切掉答案解析区、只扫**题面（题干＋选项）**，按题去重。案例题另扫解析区取定性罪名。
2. **教材**（域＋校验）：`D:\fashuo\教材\考试分析_文本.txt` 分则第十四~二十一章正文条目共 **170 个罪名**——即《考试分析》各章「第二节 本章要求掌握的内容」的全部罪名。**清单只在这 170 个里选，不自造罪名、不引外部教材口径。**

**统计口径**：一道题里出现某罪名（不论作正确答案还是干扰项）＝该罪名命中 1 题。干扰项照算——真题里罪名 **95% 以上出现在选项**，题干几乎不写罪名，选项认不出来就是丢分。

**三处失真，用这份清单时必须知道：**

- ⚠️ **教材彩色标注版自带的真题年份标注只覆盖 2019 年起**，2014–2018 一律空白；且**至少两条标注有误**——「拒不支付劳动报酬罪」标着"2020 非法单，2021 法/非法单"，与上一条「破坏生产经营罪」的标注**一字不差**（疑似排版串行），而 12 年真题全文 grep「劳动报酬」**零命中**；「强制猥亵、侮辱罪」标 2024，2024 卷同样查无。**所以频次一律以真题原文为准，教材标注只作参考列。**
- ⚠️ Anki 已于 2026-08-24 停用，分则选点不再读取卡片星级；统一只认高频考点表／十二年真题频次与教材显式考点标记两把尺。<!-- [gpt] 2026-08-24 -->
- ⚠️ **真题库 2023 年两个文件内容互换**（文件名"专业基础"的里面装的是综合卷，反之亦然）。本次统计按**卷头内容**判卷别、没按文件名，12 套齐全。**这个坑在 `D:\fashuo\真题\_文本\` 里还没修，别的脚本读那两个文件会拿错。**

## 二、辨析组＝带背的真正单位（**不是按章背，是按组背**）

**数据依据**：分则罪名 **95% 出现在选项而非题干**，考法是「给一段案情，在四个罪名里选」。真题反复把同一批罪名塞进同一道题——下面每组后面的数字是 12 年内**同题共现次数**，不是我编的分类。

**这一条决定带背怎么排：一次带一组，组内横着比区分点；绝不一个罪名一个罪名孤立地背定义。**

### 组① 财产转移型（最大组·最高频·9 个罪名全在带背盘）
`盗窃罪 / 侵占罪 / 抢夺罪 / 抢劫罪 / 诈骗罪 / 职务侵占罪 / 敲诈勒索罪 / 故意毁坏财物罪 / 挪用资金罪`
- 侵占↔盗窃 **7 次**、抢劫↔盗窃 **4 次**、抢夺↔盗窃 **3 次**、侵占↔抢夺 **3 次**、侵占↔诈骗 **3 次**、侵占↔抢劫 **3 次**
- **主轴**：占有归属（谁占有）→ 取得方式（秘密/公然夺取/暴力/欺骗）→ 处分意识与处分能力 → 非法占有目的
- 云已栽实锤：**处分能力**这道前置关卡（7 岁男孩换表案答诈骗、正解盗窃，错题本在册）

### 组② 人身结果型
`故意伤害罪 / 故意杀人罪 / 过失致人死亡罪 / 寻衅滋事罪`
- 寻衅滋事↔故意伤害 **6 次**、故意杀人↔过失致人死亡 **5 次**、故意伤害↔过失致人死亡 **3 次**
- **主轴**：主观（故意/过失/有无预见可能）→ 结果归属 → 是否"随意殴打、无事生非"（寻衅滋事的独门要件）
- 云已栽实锤：工地嬉闹推倒工友案（过失致人死亡 vs 意外事件，尺子＝**有无预见可能性**）

### 组③ 身份职务型（贪贿＋渎职合并带，主体门槛是同一把尺）
`受贿罪 / 利用影响力受贿罪 / 贪污罪 / 职务侵占罪 / 非国家工作人员受贿罪 / 行贿罪 / 滥用职权罪 / 玩忽职守罪 / 徇私枉法罪 / 私放在押人员罪 / 食品、药品监管渎职罪`
- 利用影响力受贿↔受贿 **5 次**、诈骗↔贪污 **4 次**、受贿↔诈骗 **3 次**、职务侵占↔诈骗 **3 次**、受贿↔职务侵占 **3 次**
- **主轴**：**主体身份是前置关卡**（国家工作人员 / 近亲属关系密切人 / 公司企业人员）→ 利用的是本人职权还是他人职权 → 竞合怎么处理
- 云已栽实锤 **3 条**：交通协管员打招呼案、通过妹夫撤销追逃案（都是受贿 vs 利用影响力受贿）、399 条 4 款「择一重」射程（出了射程回数罪并罚）

### 组④ 公共安全型
`以危险方法危害公共安全罪 / 交通肇事罪 / 危险驾驶罪 / 放火罪 / 投放危险物质罪 / 破坏交通工具罪 / 破坏交通设施罪 / 破坏电力设备罪`
- 以危险方法危害公共安全↔故意伤害 **3 次**
- **主轴**：**对象门槛**（"正在使用中"的设备/交通工具）→ 地界（是否在公共交通管理范围内）→ 具体危险 vs 抽象危险
- 云已栽实锤 **2 条**：破坏电力设备罪「正在使用中」的三类边界（在建电缆不算）、酒驾致同乘死伤＝交通肇事而非过失致人死亡（**先问地界再选法条**）

### 组⑤ 生产销售型
`生产、销售伪劣产品罪 / 生产、销售、提供假药罪 / 诈骗罪 / 侵犯著作权罪 / 合同诈骗罪 / 保险诈骗罪 / 强迫交易罪 / 非法经营罪`
- 假药↔诈骗 **3 次**、假药↔生产销售伪劣产品 **3 次**
- **主轴**：**两层竞合**（罪内看 149 条 2 款、跨罪看 2001 年司法解释，两条并行别混）→ 假药的口径（以非药品冒充药品）→ 主观要件（侵犯著作权罪必须**以营利为目的**）
- 云已栽实锤 **3 条**：面粉小丸冒充消炎药案、保健品冒充药品三罪案、侵犯著作权罪营利目的

### 组⑥ 妨害司法与信息网络型
`窝藏、包庇罪 / 伪证罪 / 掩饰、隐瞒犯罪所得、犯罪所得收益罪 / 脱逃罪 / 妨害公务罪 / 非法利用信息网络罪 / 非法侵入计算机信息系统罪`
- **主轴**：行为方式是作为还是不作为 → 时间点（事前通谋＝共犯，事后才是窝藏/掩隐）→ 对象
- 云已栽实锤 **2 条**：包庇罪四个开关（**只能是作为**，知情不举不构罪）、妨害公务罪边界（聚众阻碍解救被收买妇女儿童≠妨害公务罪）

### 组⑦ 毒品与风化型
`走私、贩卖、运输、制造毒品罪 / 非法持有毒品罪 / 传播淫秽物品罪 / 赌博罪 / 开设赌场罪`
- **主轴**：**牟利开关**（代购加价／截留＝贩卖；未牟利代购＝非法持有）→ 营利目的 → 聚众/开设的场所性
- 云已栽实锤：代购毒品牟利开关

### 组⑧ 自由与人格型
`非法拘禁罪 / 绑架罪 / 强奸罪 / 遗弃罪 / 侮辱罪`
- **主轴**：有无勒赎/第三人要挟目的（绑架 vs 非法拘禁）→ 扶养义务与拒不扶养（遗弃）→ 结果加重犯的因果链
- 云已栽实锤：强奸致被害人逃跑溺亡＝强奸罪结果加重犯一罪、不另定故意杀人

### 组⑨ 单列（不入组，各背各的）
`间谍罪 / 非法持有、私藏枪支、弹药罪 / 洗钱罪 / 信用卡诈骗罪 / 组织、领导、参加黑社会性质组织罪`
- 信用卡系列云已栽实锤：伪造信用卡＝伪造金融票证罪／虚假身份证明骗领＝妨害信用卡管理罪——**两行相邻别串**

> **交叉验证留痕**：云错题本 26 条刑法错题里，分则部分**全部落在上面这 9 组内**，且**没有一条是"罪名定义没背下来"**——全是区分点、前置关卡、竞合处理、门槛开关。这与共现数据是两条独立证据、指向同一个结论：**分则失分不在记忆量，在辨析**。所以带背盘只有 60 个罪名不是偷工，是把力气从"铺量"挪到"抠区分点"。

## 四、带背这 60 个罪名的执行法

**不改带背方法，只改单位**——本目录 `beisong-blueprint.md`「一·五 结构化编码五步」照走，但**每一步的对象从"一个罪名"换成"一个辨析组"**：<!-- [gpt] 2026-08-12：本地蓝本使用现役文件路径，不走旧记忆解析。 -->

1. **逻辑链**：讲这一组为什么会被真题反复放进同一道题（共现次数摆给他看）＋这组的**主轴**是哪条尺（占有归属／主体身份／对象门槛／牟利开关）。
2. **生成式**：只给罪名名单，让云**先自己排出组内区分顺序**（先问什么、再问什么），再对教材原文。
3. **组块**：一组＝一个块，标签就用主轴名（如"占有归属组"）。
4. **挂例**：**每个罪名挂一道该组的真题**——清单里每个罪名都带了年份，直接从 `D:\fashuo\真题\_文本\` 现拉原题，别自己编案情。
5. **撤梯**：白纸默出**这一组的区分决策树**（不是默单个罪名定义）＝撤到④才算过。
6. **应用锁扣**：撤④后必出 **1–2 发真题选项**，点名"用这一组的哪条尺判、怎么推"，答完苏格拉底式追问验链（[[socratic-probing]]）。

**轮次定档**（照本目录 `beisong-blueprint.md` 轮次矩阵，分则新接入，本条为分则专用）：
- **第 1 轮（现在·8 月）＝认组＋主轴**：能说出每组的主轴那条尺 + 组内罪名不漏；单个罪名只要"一句话定义 + 与组内最近的那个罪的一条区分点"。⛔ 不要求默全部四要件、不抠原文措辞。
- **第 2 轮**：每罪"四要件 + 与近似罪区分点"用自己的话说全；竞合处理规则（法条竞合默认值＝特别法优先、399 条射程、牵连犯）成表。
- **第 3 轮 A**：给案情**即答罪名 + 一句理由**；区分点脱口。
- **第 3 轮 B**：关键定义贴教材措辞（尤其**限定语**：以营利为目的／正在使用中／以非法占有为目的／数额较大）；法条分析成段。
- **第 4 轮**：只滚错题命中的组 + 挂账。

**开打顺序**（按性价比，非按教材章序）：
**组①财产转移 → 组③身份职务 → 组②人身结果 → 组④公共安全 → 组⑤生产销售 → 组⑥妨害司法 → 组⑦毒品风化 → 组⑧自由人格 → 组⑨单列**
理由：①③④⑤ 是云错题实锤最密集的四组（26 条刑法错题里占 11 条），且①的 9 个罪名出自只有 11 个罪名的侵犯财产章、密度最高。

**必须专打的病根**（[[yun-weakspot-exceptions]]、[[yun-ability-profile]]）：
- 每组带完必抠**例外与边界**（转化型抢劫的 269 条条件、结果加重犯的因果链、竞合的默认值与例外）。
- **限定语精度**是云的死穴：判✓前用 `cuoti.mjs material` 拉原文列限定语清单逐项比对，缺一个词最多记半✓（本目录 `SKILL.md` 的复检硬闸）。
- 案例题凭感觉／回避推理——**应用锁扣不许省**，必须逼出"用哪条尺、怎么推"。
