# 主观题台账数据契约

- 唯一事实源是 `.local/主观题台账.md`；写作病灶与练笔记录都留在该文件，不复制到错题本或评估 JSON。
- 机器汇总由 `node --env-file=.env.local scripts/assessment.mjs` 生成到快照 `subjective`：活动病灶、已改病灶、案例/论述练笔量、首稿/重写得分与最近练笔。
- 病灶标题保持 `### A1｜病灶名｜说明`；必须带 `首现 YYYY-MM-DD`、`最后碰 YYYY-MM-DD` 与状态。案例用 A 前缀，论述用 B 前缀，ID 不复用。
- 练笔标题保持 `### YYYY-MM-DD｜案例 ...` 或 `### YYYY-MM-DD｜论述 ...`；15 分制必须显式写 `首稿 X/15`，有重写时同节写 `重写稿 X/15`。
- 一道题只建一个练笔节，重写不另起一题；知识错误仍进 `study_error`，写作结构病灶只留本台账。
- 案例或论述任一类型少于 3 道时，不得从单题/单类成绩外推整张 180 分主观卷。
- 明确定日期的复练用 `schedule.mjs add`，完成用 `schedule.mjs done`；排期只管时间，病灶是否解决仍以本台账为准。
