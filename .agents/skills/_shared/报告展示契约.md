# 学习报告展示契约

<!-- [gpt] 2026-08-10：统一日报、周报、阶段评估与里程碑的阅读层级；只改展示，不改事实口径。 -->

四类报告共用同一条阅读路径：**先判定 → 再行动 → 后证据**。报告可以保留完整证据，但不能让用户先穿过一整页数据才能找到“现在怎么办”。

## 统一三层

1. **判定层（首屏）**：只放时间范围、红黄绿/控制器状态、一句话结论和最多 3 个决定性数字。结论不超过两行。
2. **行动层（第二屏）**：只放会改变下一步的事项。每件必须有优先级、截止/时段、验收标准和理由；同一动作不得在结论、风险、处方里重复写三遍。
3. **证据层（按需展开）**：完整数据、口径、异常、明细与来源放这里。优先表格和短句，不再复述判定层结论。APP 默认折叠，Markdown 报告固定放末尾。

## 视觉与文字纪律

- 状态符号只表达状态：`🟢/🟡/🔴`、`✅/⚠️/❌`。标题不靠一排 emoji 装饰；同一层最多一种强调色。
- 一个数字原则上只出现一次。后文引用时说“该缺口/该红线”，不要重新抄整组数字。
- 每段只回答一个问题；普通段落不超过 3 句，连续项目超过 5 个就改成表格或移入证据附录。
- “做了什么、表现证据、当前状态”分开：完成任务不等于掌握，销账事件不等于主题稳定，稳定不等于考试就绪。
- 数据缺失放在它影响的判断旁边，写“因此暂不能判断 X”；不要另堆一大段“数据盲区大全”。
- 不用“综上所述”“值得肯定”“继续保持”等无决策信息的句子；末尾不再重复一遍开头结论。

## 日报：只解决今晚

固定顺序：

```markdown
# 日报 YYYY-MM-DD（周X）· 距初试 N 天
> 一句话：<今晚唯一靶心，≤24字>

## 今晚行动
- **派单**：[P0] ... ｜ [P1] ...
- P0 验收：<做到什么算完成>
- P1 验收：<做到什么算完成>

## 昨日对账
- **昨日结算**：<X/Y + ✅/⚠️/❌ 极简结果>
- 只展开未完成、部分完成和一条最重要的正证据；其余进证据附录。

## 当前告警
- **断档**：<只报会改变今晚派单的断档；无则写无>

## 证据附录
- **今日流水**：<截至生成时的半天切面>
- <逐件结算依据、完整流水和口径说明>
```

硬上限：行动 1~3 件、P0 最多 1 件；首屏不展示完整欠账池、14 天热力、所有主题与所有带背明细。

## 周报：先定下周作战标准

固定顺序与固定 H2 标题（APP 展示器据此分层）：

```markdown
## 本周结论
> 🟢/🟡/🔴 <P0严格兑现率 + 控制器模式 + 一句话判断>

## 本周变化
### 做对了
- 最多 3 条，只写改变趋势的进展。
### 偏航了
- 最多 3 条，只写会影响下周安排的问题。

## 下周作战卡
### [P0] <动作名>
- 截止/时段：...
- 验收：...
- 理由：...
（P0≤2；总计 3~5 件；每件只出现一次）

## 证据附录
- 计划兑现、学习动作、错题事件/主题、知识迁移、带背与数据异常的紧凑表或短句。
```

不再写“先对五件账→四个真进展→四个真问题→节奏对照→五件指导→全局项→一句话钉死”的长链；这些内容分别压进“本周变化、作战卡、证据附录”。

## 阶段/月度评估：突出目标差距

固定顺序：

1. `## 先看结论`：红黄绿、控制器、离目标最关键缺口、预测所处层级。
2. `## 目标差距`：一张紧凑表，列“科目/当前可靠证据/目标或底线/缺口/下一动作”；没有模考时明确写不可估分，不用四维冒充分数。
3. `## 趋势变化`：相对上一份只写最多 3 个改善和 3 个恶化；不重复全量现状。
4. `## 主要风险`：最多 3 条，每条固定“触发 → 后果 → 最小动作”。
5. `## 行动处方`：3~5 件，P0≤2，写日期、时段、数字验收并落结构化排期。
6. `## 证据附录`：完整四维、两条错题轴、主观题、英语、日报执行、数据质量及来源。

阶段评估的核心不是“展示我查了多少表”，而是回答目标差多少、斜率是否够、资源该移到哪里。

## 里程碑：突出关口决策与产能账

固定顺序：

1. `## 关口判定`：在轨/偏航/失守；下一关口日期；一句话说明是否还有可行路径。
2. `## 上次处方审计`：只列上次 P0 的目标、证据、判定，不重放整月流水。
3. `## 产能账`：`剩余可用 - 必办需求 = 余量/缺口`，同时写“必须保护什么、必须砍什么及代价”。
4. `## 到下一关口`：最多 2 个 P0，必要时 1 个 P1；每件带日期、时段和数字验收。
5. `## 证据附录`：逐科轮次、风险与数据口径。全量四维只在它改变关口结论时进入正文。

里程碑不再复制一份月度评估。月度评估回答“离目标多远”，里程碑只回答“这一关过没过、剩余产能够不够、下一段保什么砍什么”。
