# 智能教练数据契约

智能教练层只从既有事实源**派生决策视图**，不新建可变的“掌握状态真相”。入口：

```powershell
node --env-file=.env.local scripts/coach-engine.mjs snapshot
node --env-file=.env.local scripts/coach-engine.mjs dispatch --limit 3        # 预览
node --env-file=.env.local scripts/coach-engine.mjs dispatch --limit 3 --write # 写唯一排期账
```

快照写入 `.local/coach-engine-snapshot.json`，也内嵌于 `.local/assessment-snapshot.json` 的 `coachEngine`。两者都是可重算缓存，不是新的学习事实源。

## 七阶段状态机

`发现 → 确认 → 强化 → 短期通过 → 冷却观察 → 稳定 → 长期保持`

- 发现：主题尚未确认分类；确认：已分类但尚无合格冷检。
- 强化：最近一次冷检 `partial/fail`，或旧通过后又出现新的 open 事件。
- 短期通过：刚出现一次合格跨日通过；冷却观察：已有通过，等待下一间隔复检。
- 稳定：至少两个不同北京日通过，期间无更新失败且没有新的 open 事件；长期保持：至少三个不同北京日通过并进入低频轮换。
- 同日订正、刚看原文后的复述、明确写“当场/不算/问法打折”的通过不升级。任何新失败或复发都允许降级。
- 数据库的事件状态、主题 mastery 状态和带背挂账状态仍按各自契约写；七阶段状态是跨轴派生视图，不直接回写这些字段。

## 遗忘与风险

- 有“通过 → 后来失败”的历史时，以实际间隔中位数估计下一复检间隔；没有时使用状态默认间隔，并标 `confidence=low`。
- `riskScore / dropRisk / readinessIndex` 都是 0–100 **调度分**，用于队列排序，不是遗忘概率、能力百分比或卷面分。
- 背诵输出 `topDropRisk` 前 20 项；不能再只按“最久未碰”机械抽题。最终选择仍需结合当天章节、周报 P0/P1 与用户状态。
- 科目风险结合量化 v3、学习新鲜度、复发主题和高风险背诵点。没有成套模考时 `calibration=uncalibrated`、`canProjectScore=false`；禁止输出伪卷面分或上岸率。

## 自动派单

- 自动派单只处理**既有错题主题和带背挂账的复检义务**，不创造新章节目标、不改周报优先级。
- 每次最多 3 件、P0 最多 1 件、优先跨科；候选与分数透明保存在快照。
- `dispatch` 默认只预览；只有 `--write` 才写 `.local/复盘排期.md` 的结构化区。写入前后都用同一解析器校验。
- 同一知识对象已有未完成结构化排期时幂等跳过；完成仍用 `schedule.mjs done` 回写。日报只消费排期，不把派单视为已学习或已掌握。
