# 评估事实快照契约

- 先运行 `node --env-file=.env.local scripts/assessment.mjs`；固定日期审计用 `--today YYYY-MM-DD`。输出同时写 `.local/assessment-snapshot.json`。
- 快照一次采集量化 v3.1、学习流水、错题事件/主题、冷复检、答疑卡点、带背存量/迁移、日报执行、结构化排期、主观题、知识考试就绪、学习控制器、预测分层/概率回测与目标死线。任一必需数据库查询或台账结构报错时整体失败，不生成全零报告。<!-- [gpt] 2026-08-10 -->
- `quantV3` 与 APP 今日页共用 `src/lib/quant-v3.mjs`，禁止在 Skill、报告或临时脚本里复制公式。跨 v3.0/v3.1 仍不可直接比较。
- `dailyExecution.strictExecutionRate` 只把 ✅ 算严格完成，⚠️ 单列，不把“有记录”冒充“已完成”。
- `reviewSchedule.overdue/dueToday/upcoming` 只含 `schedule.mjs` 的结构化行动项；旧散文只在 legacy 计数里显示为数据债。`coachEngine.controller` 只统计完整 `plan_id/week/source/weight` 的验收单元，模式由排期重算，不另存真相。<!-- [gpt] 2026-08-10 -->
- `recite.flow30d` 只认同一带背 Markdown 内 append-only 流水；0 表示 0 条可审计迁移，不代表历史上从未迁移。
- `subjective.scores` 是真实样本水位。案例或论述任一类型少于 3 道时，不得把单类小样本线性外推成整张 180 分主观卷；只报样本与风险。
- `coachEngine.examForecast` 的层级闸门固定为：完整同口径模考 `N<3` 只结构风险，`N=3~5` 只分数趋势区间，`N≥6` 才目标达成概率。百分比自动写 `.local/概率预测台账.md`，同证据版本幂等；`probabilityForecasts` 报已对账 N、Brier、偏差与分桶。<!-- [gpt] 2026-08-10 -->
- 快照不自动给“上岸率”。叙事判断仍由 pinggu-pc 目标反推，并逐条引用快照字段；五科概率不得直接相乘或平均成胜算。
