# 法硕答疑

目标是快速给出可核验、符合考试口径的结论。不要把内部流程、长清单或检索日志倾倒给用户。直接路径同样使用 Skill Run 审计，但不强制个人全盘快照。

## Codex 正常执行快路径

规定命令成功即以结构化回执为准；正常执行禁止读取 `scripts/` 实现、全库 `rg`、扫描 `.local`、运行 `git status` 或加载与当前争点无关的整份方法论。只有命令明确失败且错误信息不足时，才定向读取报错涉及的一个文件片段；一次仍不能推进就安全结束 Run 并报告阻塞，不得重复兜圈。

## 默认快路径

1. 先运行 `node scripts/skill-run.mjs start --skill ask-pc --subject <科目> --kind answer --json`。用户已经给出问题，不加载个人快照。
2. 拆出题目中每个会影响答案的核心概念或争点。单一争点运行 `node --env-file=.env.local scripts/cuoti.mjs material <连续短词> [refine] --run <SR-ID>`；多个独立争点一次运行 `material-batch`，但每个争点分别查询。检索命令必须带 `--env-file=.env.local`，否则读不到档案根直接失败。<!-- [claude] 2026-08-24 -->
3. 内部完成六项核对：题型与问法、心得提示、易混点、《考试分析》锚点、真题口径、法律更新与前后矛盾。六项是思考检查，不是固定展示模板。
4. 按下列裁判顺序定结论：用户明确指定的参考答案或评分标准 → 《考试分析》 → 讲义 → 法硕真题。心得和易混库只负责提示争点。材料未明文时明确降级，不把学理争议写成法硕定论。
5. 输出“结论 → 关键规则 → 题干涵摄/选项排除 → 易错边界”。把出处紧贴对应结论；末尾只给紧凑证据条，不重复整段检索结果。
6. 检索完成后运行 `node --env-file=.env.local scripts/ask.mjs preflight --run <SR-ID> --category <科目/章节/题型>` 自动落 `preflight_checked` 并取得清单，把清单原样放进答案第一段；证据卡用 `ask.mjs card --file <证据卡.json>` 渲染，只展示脚本输出。末检后运行 `node scripts/skill-run.mjs end --run <SR-ID> --phase answer --done response_verified --ref <教材/真题锚点短引用>`。<!-- [claude] 2026-08-25：preflight_checked 已改脚本签，`--done` 会被拒。 -->

## 题型纪律

- 用户有两个稳定的读题毛病，决定怎么解释：①**日常语义压过专业标签**（把"收取孳息"读成"取得所有权"、"徇私"读成"徇情"、"法的适用"按日常义理解）——解释术语时先把它和同形日常词切开，再讲内容；②**分类层与定罪层混淆**（"算不算 X"和"构不构成 X"搅在一起）——回答前先钉住问的是哪一层，别答串。<!-- [claude] 2026-08-30：原只存在于 Claude 现役厚入口，仓库无副本；该入口收敛为薄指针时移入权威版，两个宿主同吃。 -->
- 选择题逐项判定，先识别题目问“正确”还是“错误”，再汇总答案。
- 案例按“规则—关键事实—涵摄—法律后果”作答；多主体时先分主体与责任范围。
- 概念辨析先给最小区分标准，再讲边界与常见陷阱。
- 题干有明显互斥、缺字或歧义时列出会改变答案的两种解释，不擅自补事实。
- 引用必须含材料名、科目、章节/标题、页码（找不到写未知）及行号；残句不能拼成规则。没有可靠锚点就如实说，并降低信心。
- 默认只用本地材料。仅在本地材料冲突、法律更新无法确定或用户明确要求时联网，并区分考试口径与实务口径。

## 仅在需要时加载

- 用户明确要求“结合我的进度/错题”，或历史关联能实质改变讲法时：先独立定完本题，再运行 `node --env-file=.env.local scripts/skill-context.mjs ask <科目> --run <SR-ID>`。不要为了寒暄或普通概念题加载个人账本。
- 要出理解检验题时：材料检索后生成完整草稿，运行 `question-integrity.mjs`；只有 PASS 草稿才能展示，再以 `checkpoint --phase question --hash <SHA256>` 等待作答。
- 用户真实答错、要求记错题，或具体卡点跨会话仍未解决时，才读取 [数据契约.md](数据契约.md) 与 [学习事实层](../_shared/学习事实层.md) 并写回。普通提问不落账。
- 涉及个人知识图谱、法律更新触发词、复杂多主体题、卡点状态或写回细节时，再读取 [完整运行参考.md](完整运行参考.md) 的对应小节；不得无条件全文读取。

## 输出底线

- 先回答用户问的内容，不以“预检清单”开场。
- 证据条至少说明教材/讲义锚点；真题不适用时可省略，不为凑卡片编题号。
- 不报伪精确置信度。只有证据单一、材料冲突或结论存在合理不确定性时才标信心与核对建议。
