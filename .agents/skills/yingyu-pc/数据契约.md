# yingyu-pc 数据契约：能力画像 × 错误生命周期 × 作文个人装配

> 目标：让一次真实训练同时喂给三个消费者，而不是维护三套互不相认的账。
> 事实分层：`.local/英语训练台账.md` 记录本次细维能力观测；Supabase `learning_attempt` 记录阅读/作文首稿/重写的共同分母，`study_error/error_topic/error_review` 记录错误生命周期；`.local/英语作文语料.md` 保存可调用表达。画像和计划每次从这些事实重算，不另存“结论真相表”。<!-- [gpt] 2026-08-10 -->

## 一、会话键：三套事实的共同主键

每场训练生成唯一键：

- 阅读：`EN-YYYYMMDD-R-年份-T篇号`，如 `EN-20260810-R-2017-T2`。
- 作文：`EN-YYYYMMDD-W-年份-类型`，如 `EN-20260810-W-2024-REPLY`。

同一键同时写进：

1. 英语训练台账的 `会话键`；
2. `cuoti.mjs review ... --session <会话键>`；
3. `learning_attempt.session_key`；
4. 作文语料使用记录对应的训练条目。

禁止把同一篇的首稿与重写拆成两个会话；二者是同一训练事件的两个阶段。

## 二、英语训练台账格式

### 阅读

```md
## 2026-08-10｜阅读｜2017 Text 2
- **会话键**：EN-20260810-R-2017-T2
- **诊断依据**：答案键+原文
- **得分**：4/5
- **用时**：18
- **能力观测**：定位=3/4｜改写=2/4｜范围程度=1/4｜观点归属=NA｜推理边界=2/4｜长句归属=NA｜置信校准=1/4
- **门槛观测**：限时=pass
- **证据锚点**：Q23 定位句……；原答……；正确项改写……
- **生命周期动作**：新增 #事件 → T#主题；或 T#主题 novel_case/degree_term pass
- **语料调用**：无
```

### 作文

```md
## 2026-08-10｜作文｜2024 小作文
- **会话键**：EN-20260810-W-2024-REPLY
- **诊断依据**：考研评分档
- **载体**：回信
- **得分**：7/10
- **用时**：20
- **能力观测·首稿**：任务完整=2/4｜载体处理=3/4｜结构组织=3/4｜论证展开=NA｜语言准确=2/4｜语料调用=1/4
- **能力观测·重写**：任务完整=4/4｜载体处理=3/4｜结构组织=3/4｜论证展开=NA｜语言准确=3/4｜语料调用=3/4
- **门槛观测·首稿**：限时=pass｜要素清单=fail
- **门槛观测·重写**：限时=NA｜要素清单=pass
- **证据锚点**：题干要求2问；首稿漏第2问；重写逐问回应
- **三病根**：漏问2｜句子主谓错误｜结尾未收口
- **生命周期动作**：新增 #事件 → T#小作文要素漏答
- **语料调用**：E2-XXXXXXXX=pass｜E2-YYYYYYYY=partial
```

### 观测标尺

| 分值 | 含义 |
|---|---|
| 0/4 | 未出现、方向相反或根本错误 |
| 1/4 | 有痕迹，但主干仍错 |
| 2/4 | 部分完成，缺关键一环 |
| 3/4 | 基本正确，只有小遗漏 |
| 4/4 | 完整准确，且本次无需提示即可复现 |
| NA | 本篇没有真实测试该能力，不得打分 |

硬规则：

- 阅读观测只能写 `答案键+原文`；作文默认写 `考研评分档`。用户当次指定参考答案、评分表或采分标准时必须写 `用户指定标准`，并以用户标准为准。
- 只有交卷后的表现才能评分；题面预输入、高亮或教练提示后的结果不得冒充 clean 能力。
- 每个维度 1–2 个样本只展示原始观察；3 个样本才出暂定比例，5 个标稳定，6 个才计算近三次趋势。
- 历史 `study_log.accuracy` 只能证明篇级成绩，不能反推“定位、改写、推理”等细维度。
- 历史 `study_log.accuracy` 不补造 `learning_attempt`。新阅读一篇写一条 `objective_question` 尝试，`score/max_score=N/5`；作文首稿写 `subjective_answer + role=primary`，同会话重写写新来源 ID 且 `role=rewrite`。`void` 留审计但排除有效分母和得分率。<!-- [gpt] 2026-08-10 -->

## 三、错题事件与长期弱项必须分层

| 情形 | 动作 |
|---|---|
| 答错且机制明确 | 新增 `study_error`，关联或创建 `error_topic`；诊断可 confirmed |
| 答错但原因不清 | 新增事件，诊断 pending；讲完仍不清楚就不强贴病根 |
| 答对但犹豫 | 写英语训练台账；不因一次犹豫直接制造长期病根 |
| 同一犹豫机制跨两场复现 | 升为候选长期主题，用户认领或证据充分后 confirmed |
| 普通题碰巧答对 | 只算能力观测，不自动成为销账证据 |
| 针对既有主题、无提示的新篇变式 | 记录 `error_review`；满足 clean/application/L3+ 才参与迁移证明 |

常用英语栽点映射：

| 阅读/作文表现 | `failure_pattern_code` | 首选验证轴 |
|---|---|---|
| 过度推理、把可能写成必然 | `scope_expansion` 或 `degree_strength` | `rule_boundary` / `degree_term` |
| 偷换人物、机构或观点主体 | `subject_confusion` | `subject_condition` |
| 偷换行为对象或评价对象 | `object_confusion` | `object_condition` |
| 答非所问、把例子内容当例证功能 | `question_layer` | `question_layer` |
| 漏题干要求、回信漏答一问 | `element_omission` | `element_structure` |
| 长句碎块认错主人、事实读反 | `fact_misread` | `fact_signal` |
| 会认表达但作文调不出来 | `recall_application_gap` | `fact_signal` / `integrated` |
| 作文采分句表达漏点 | `expression_gap` | `element_structure` |

示例命令只表示形状，实际 ID、原答和锚点必须来自本场：

```powershell
node --env-file=.env.local scripts/cuoti.mjs add 英语 "推理题把 may 扩成 must（2017-T2-Q28）" --topic "推理题×过度推理" --cause boundary_miss --pattern degree_strength --diagnosis confirmed --anchor "2017-T2-Q28 定位句+原答"
node --env-file=.env.local scripts/cuoti.mjs review 12 pass --event 34 --variant novel_case --axis degree_term --pattern degree_strength --diagnosis confirmed --angle "新篇改变程度词" --anchor "2018-T1-Q22" --note "原答及逐词依据" --session EN-20260817-R-2018-T1
```

销账沿用数据库硬门槛：最近失败后至少两条 clean L3+ application pass、两个不同验证轴、至少一次冷检；主题 stable 还要求跨两个北京日、跨度至少 7 天且至少一次 L4+。`yingyu-pc` 不再使用“连续两题对了就销账”的旧捷径。

## 四、作文语料状态

| 状态 | 事实含义 | 能否进入后期背诵池 |
|---|---|---|
| `fixed` | E1 格式等固定规范 | 可以，现在就背 |
| `seed` / 🌱 | 外部或阅读提供的启动表达，云尚未写过 | 不可以 |
| `used` | 云在训练中调用过，但尚未形成个人稳定版本 | 不可以 |
| `owned` / ✅ | 云自己写过、经批改定稿并能再次调用 | 可以，11–12月背 |

句子 ID 由“语料格子 + 句子文本”稳定哈希生成，运行 `english-growth.mjs profile/compose` 可查看。修改句子文本意味着生成新版本 ID；旧训练记录保留旧 ID，不伪造连续性。

作文个人装配器只输出：

1. 题干要素 checklist；
2. A/B/C/E 功能骨架；
3. 与题材匹配的 fixed/owned/used/seed 表达；
4. 本篇只练的一个能力约束。

首稿前禁止输出完整范文。首稿后才能给逐句升级稿，并把成功句回写为 ✅。

## 五、运行命令

```powershell
# 开场：重算画像与语料状态
node --env-file=.env.local scripts/english-growth.mjs profile

# 派英语内部下一项；作文锚点由复盘排期判定，到点时加 --essay-due
node --env-file=.env.local scripts/english-growth.mjs plan
node --env-file=.env.local scripts/english-growth.mjs plan --essay-due

# 作文题面解析后生成个人装配包；每个题干要求单独传一次 --require
node --env-file=.env.local scripts/english-growth.mjs compose --carrier reply --theme d2 --require "回答展示什么" --require "回答能够提供什么帮助"

# 格式健康检查
node scripts/english-growth.mjs check
```

`plan --offline` 只供本地测试；它不读取 Supabase 生命周期，严禁据此宣称“没有到期复检”。
